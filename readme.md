# Batcave 🦇

A fan-made Batman theme pack for Kiro Crew.

**Dark mode** is the Batcave: dark stone walls, Batcomputer blue glow, Bat-Signal gold. A live cave scene plays behind the chat:

- Batcomputer with six working screens (Gotham map, data feed, radar, waveform, bars, bat logo)
- Batman in the chair, typing
- Alfred stepping out of the elevator with coffee every minute or so
- Bat swarms crossing the cave
- Dripping stalactites and a waterfall
- Batmobile, suit cases, and the giant penny

**Light mode** is Wayne Manor by day. Bot name: Alfred.

The scene runs only in dark mode. With "reduce motion" on, it shows one still frame.

## Install

Settings → Display → Install theme, then paste:

```
https://github.com/Justinyourhead/kirocrew-theme-batcave
```

Switch to dark mode to see the cave.

## Preview the scene alone

Open `overlays/ambient.html#preview` in a browser.
